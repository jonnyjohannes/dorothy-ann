## Abstract

Keep the completed native overflow and keyboard behavior. Remove the user-selectable Primary accent. Keep prompt/search focus borders ink/paper; the updated native insertion caret cycles scheme accents and uses block shape where supported. The latest owner adjustment returns Escape/scroll focus to a random accent outline around the scrollbar indicator; the same random accent highlights the prompt and fuzzy-listbox search focus. Give each visible scrollbar thumb a scheme color drawn unpredictably on page load; let thread-row highlights advance through scheme accents each time the active row changes by pointer or keyboard, wrapping both the row index and hue sequence. Use bundled Source Sans 3 before Helvetica Neue for UI and prose, and Source Code Pro only for code-like text. Keep the native insertion caret, with rotating color and a larger block shape where the browser supports it. Other color-constellation redesign is out of scope.

## Flow

```text
editing focus: native caret ──each accent for 4s; native blink
scroll focus: scrollbar indicator outline ──random shared focus accent; thumb ──independent scheme hue
/threads: active row changes ──next solid scheme swatch + legible foreground ──wrap hue; arrows wrap row
other commands/evidence/Markdown accents ──existing relationship policies
```

User-turn quote rules use the `/image` hue. No Primary accent control or hidden preference picks one color for everything. Keyboard navigation remains visible and functional. Code has a deliberate Source Code Pro face; UI/prose prefers bundled Source Sans 3 and falls back through Helvetica Neue.

## Decisions

- **Focus vs constellation:** prompt/search focus borders remain ink/paper; the native insertion caret rotates scheme colors. The owner-approved visual follow-up frames the full scrollable content region in a legible `/video`-family hue; the scrollbar has no separate focus outline and thumbs keep independent scheme colors. Thread-row selection is not focus color; it moves through solid scheme swatches with matching legible foreground.
- **Cursor (updated):** keep the browser-native insertion caret, restore its rotating scheme color, and use `caret-shape: block` behind feature detection as the most compatible native larger-caret option. Unsupported browsers retain their native default caret; no overlay or simulated caret. Respect reduced-motion by stopping color animation on a static scheme accent.
- **Randomness:** one fresh randomized palette order per document load, never persisted; a repeated hue on a later load is valid randomness. Stub the random source in tests, not the production color choice. Distinctness is bounded by actual palette variety. For >8 mounted reservations, Jonny chose stable hue over guaranteed distinct visible thumbs when dormant holders return.
- **Thread row sequence:** user-driven active-index change increments an independent palette counter. Both row navigation and hue sequence wrap; filtering does not consume a color. Selected-row fill remains a tint with readable text, not an ink/paper inversion.
- **Preserved relationships:** reuse the homepage `/image` and `/video` hue tokens for the approved user-turn and scroll-focus details and the matching command foreground shades for active rows. Do not alter command hue order/AA foreground choices or source/evidence/citation identity. Monochrome remains monochrome.
- **Scroll focus (updated):** V8 supersedes V6's full-region frame. Escape/scroll focus outlines the scrollbar indicator itself. Use one random accent slot per document load for this outline and the prompt/thread-search focus highlights; the thumb's independently randomized slot remains separate. If a custom indicator cannot mount, retain the focused scroll-surface outline as fallback.
- **Delivery:** keyboard/Escape milestone is only local on `release/v1.2.2`; Jonny tests release branches, not worktrees. Future color/font work stays on the isolated work branch until verified and explicitly integrated.
