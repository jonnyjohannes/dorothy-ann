## Abstract

Keep the completed native overflow and keyboard behavior. Remove the user-selectable Primary accent. The native insertion caret cycles scheme accents and uses block shape where supported. Text selection stays ink on paper. One random per-screen accent is shared by scrollbar focus, scrollbar thumbs, prompt focus, and fuzzy/thread-search focus; it remains stable on that screen and rerolls on another route or reload. Let thread-row highlights advance through scheme accents each time the active row changes by pointer or keyboard, wrapping both the row index and hue sequence. Use bundled Source Sans 3 before Helvetica Neue for UI and prose, and Source Code Pro only for code-like text. Keep the native insertion caret, with rotating color and a larger block shape where the browser supports it. Other color-constellation redesign is out of scope.

## Flow

```text
editing focus: native caret ──each accent for 4s; native blink
scroll focus: scrollbar indicator outline + thumb ──random shared focus accent; prompt/search focus ──same accent
text selection ──ink on paper
/threads: active row changes ──next solid scheme swatch + legible foreground ──wrap hue; arrows wrap row
other commands/evidence/Markdown accents ──existing relationship policies
```

## Decisions

- **Focus vs constellation (updated):** prompt/search focus, scrollbar focus, and native/custom scrollbar thumbs share one random per-screen accent; text selection stays ink on paper. The native insertion caret rotates scheme colors. Thread-row selection is not focus color; it moves through solid scheme swatches with matching legible foreground.
- **Cursor (updated):** keep the browser-native insertion caret, restore its rotating scheme color, and use `caret-shape: block` behind feature detection as the most compatible native larger-caret option. Unsupported browsers retain their native default caret; no overlay or simulated caret. Respect reduced-motion by stopping color animation on a static scheme accent.
- **Randomness (updated):** the shared focus/scrollbar accent is randomized per pathname/screen and rerolls on reload; it is not persisted. Stub the random source in tests, not production. V12 supersedes C3's independent thumb palette and >8-slot reservation behavior.
- **Thread row sequence:** user-driven active-index change increments an independent palette counter. Both row navigation and hue sequence wrap; filtering does not consume a color. Selected-row fill remains a tint with readable text, not an ink/paper inversion.
- **Preserved relationships:** reuse the homepage `/image` hue for user-turn rules and matching command foreground shades for active rows. Do not alter command hue order/AA foreground choices or source/evidence/citation identity. Monochrome remains monochrome.
- **Scroll focus (updated):** V8 supersedes V6's full-region frame. Escape/scroll focus outlines the scrollbar indicator itself. V12 shares V11's per-screen random accent across the indicator outline, scrollbar thumbs, and prompt/search focus; text selection remains ink on paper. If a custom indicator cannot mount, retain the focused scroll-surface outline as fallback.
- **Delivery:** keyboard/Escape milestone is only local on `release/v1.2.2`; Jonny tests release branches, not worktrees. Future color/font work stays on the isolated work branch until verified and explicitly integrated.
